# Product

## Register

brand

## Users
Developers and founders who use Claude Code and want better decision-making in their workflow, plus prospects evaluating the author's credibility (Compound Club, advisory). They are technical, skim fast, and distrust marketing fluff. Context: reading to decide whether to install the skills, or arriving from a link to judge the thinking behind them.

## Product Purpose
The public documentation and showcase for the Rayo OS decision skills, a set of decision-making tools (FATE, MCDM, OOC/EMR, CTFAR, the Ship Gate, a router) that run inside Claude Code. Success: a developer installs the productivity plugin after reading, and a prospect comes away thinking "this person thinks clearly." It is luck-surface for the IP.

## Brand Personality
Editorial, calm, considered. Quiet confidence, typography-led, generous space. The voice is sharp and specific: no fluff, no hedging, no em dashes. "A loop, not a list." It should read like a well-set essay by someone who ships, not a SaaS product page.

## Anti-references
- Vanilla Starlight default (what it is now: generic theme, no identity).
- Generic SaaS-cream / corporate docs: warm near-white background, rounded cards everywhere, the 2026 AI-docs monoculture.
- Overdesigned or gimmicky: glassmorphism, gradient text, motion noise, hero-metric templates.

## Design Principles
- Practice what you preach: docs about clear decisions should themselves model clarity.
- Typography carries the brand; color stays restrained (editorial, one considered accent).
- Show the composition: the "leads to" graph and the doc pattern are the product, make them central and legible.
- Signal density: every element earns its place; no scaffolding (no eyebrow kickers, no 01/02/03 markers).
- Fast and quiet: instant, readable, accessible; motion only where it clarifies.

## Accessibility & Inclusion
WCAG AA: body text contrast >=4.5:1, large text >=3:1. Full reduced-motion alternatives. Readable measure (65-75ch). Never rely on color alone.
