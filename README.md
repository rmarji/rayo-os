# Rayo OS — docs

Documentation site for the Rayo OS decision skills, built with [Astro Starlight](https://starlight.astro.build/).

Live: https://rmarji.github.io/rayo-os/

## Develop

```sh
npm install
npm run dev      # local preview
npm run build    # static build to dist/
```

Deployed to GitHub Pages on every push to `main` (`.github/workflows/deploy.yml`).
