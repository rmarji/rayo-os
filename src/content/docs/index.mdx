## What this is

A set of decision-making skills you run inside Claude Code, organized by life-domain. Each domain is a plugin; inside it, **numbered command pipelines** for sequences and **trigger-named skills** for the engines.

## The philosophy

A loop, not a list. Skills run solo, chain into a pipeline, or route to each other. Every skill names what it leads to, so they compose instead of sitting in a flat list.
