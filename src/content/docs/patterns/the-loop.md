title: A loop, not a list
description: How the skills compose.
---

Skills run solo, chain into the decide pipeline, or route to each other. Every skill page ends with a "leads to," so they compose instead of sitting in a flat list.

## Implication map

```text
route ─┬─ new opportunity ──→ fate ────→ (pursue) → ship-gate → log
       ├─ many options ─────→ mcdm ────→ ship-gate
       ├─ values-level ─────→ ooc-emr ─→ ship-gate
       └─ stuck / reacting ─→ ctfar ───→ back to route
```

## The doc pattern

Every skill follows the same shape, adapted from [impeccable.style](https://impeccable.style/docs/):

**tagline → when to use → how it works → try it → pitfalls → leads to.**

The "leads to" line is what turns the skills into a graph the model can compose, instead of a flat list of tools.
