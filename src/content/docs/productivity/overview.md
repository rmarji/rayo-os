The productivity domain: a five-step decide pipeline plus six decision-skill engines.

## The decide pipeline

Commands you invoke in order:

1. **frame** — state the decision, the mode, the stakes, reversibility.
2. **route** — diagnose the stuck-shape, pick the tool.
3. **score** — run the chosen tool (fate or mcdm).
4. **call** — make the call: one recommendation with tradeoffs.
5. **log** — record the decision, then run the Ship Gate.
